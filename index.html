Computational Curriculum Studies

Preview: three concepts as eva_buch sees them (in 3D)

Each point below is one excerpt from a real German K–12 curriculum standard that mentions the concept named above it. eva_buch uses a language model (BERTopic) to group excerpts that discuss similar ideas, then a second technique (UMAP) arranges those groups in 3D space so excerpts with related meaning sit near each other. Color marks which school subject each excerpt comes from — how mixed the colors are is a rough visual read on how interdisciplinary that concept actually is across the curriculum, versus how concentrated in one subject.
